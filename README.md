# Thermo Sandbox – 2D Particle Simulation

An interactive, GPU-accelerated 2D Thermodynamics & Particle Simulation virtual laboratory running directly in the browser.

## Features
- **GPU-Accelerated WebGL 2**: 20,000+ particles rendered smoothly at 60 FPS.
- **Thermodynamic Triad**: Thermal Reservoirs (constant T), Porous Heat Exchangers, and Solid Thermal Blocks.
- **Valves & Fluid Dynamics**: Manual valves, directional Check Valves, and Pressure Relief Valves (PRV).
- **Piston Work & Expansion**: Free displacers, spring accumulators, and motorized compressors/expanders.
- **Population Regulators & Sinks**: Real-time particle injection and vacuum absorption.
- **Live Telemetry Dashboard**: Real-time charts for temperature, pressure, volume, particle count, and P-V diagrams.
- **Zero Dependencies**: Runs 100% locally in any modern web browser.

## Quick Start
- **Direct**: Open ParticleLab_Standalone.html in your browser.
- **One-Click**: Run Start_ParticleLab.bat to sync source files and launch.
